# QW0031: Format amount literals

Numeric literals used with `Qowaiv.Financial.Amount` should use formatting for improved
readability. This includes proper thousand separators (digit separators in C#) and 
decimal places.

This rule helps ensure that numeric literals representing monetary amounts are
consistently formatted, making them easier to read and reducing the risk of errors.

## Non-compliant
```csharp
1200.Amount();
100.0.Amount();
88.0m.Amount();
(Amount)23000.00;
```

## Compliant
```csharp
1_200.Amount();
100.00.Amount();
88.00m.Amount();
23_000.00.Amount();
```
