# QW0030: Prefer single value objects over data annotations

To reduce primitive obsession, use single value objects (SVOs) instead of
[primitive types](https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/built-in-types)
(like `string` or `int`) decorated with validation attributes.

This rule advices to use Single Value Objects (SVOs) to ensure validity and
express the intent of models.

## Non-compliant
```csharp
public class MyModel
{
    [EmailAddress]
    public string Email { get; init; }

    [Url]
    public string Url { get; init; }

    [Base64String]
    public string Base64 { get; init; }
}
```

## Compliant
```csharp
public class MyModel
{
    public EmailAddress Email { get; init; }

    public Uri Url { get; init; }

    public BinaryData Base64 { get; init; }
}
```
